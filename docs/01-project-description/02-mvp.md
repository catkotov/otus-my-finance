# Минимально жизнеспособный продукт (MVP)

| № | Функция                            | Описание функции                                                                                                                                                      |
|---|------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 1 | Ввод данных о доходах              | Пользователь может вводить данные как о регулярных доходах, так и разовых.                                                                                            |
| 2 | Ввод данных о расходах             | Пользователь может вводить данные как о регулярных расходах (коммунальные платежи, погашение кредита и т.п.), так и о разовых расходах (покупки в интернет/магазинах. |
| 3 | Ввод данных о планируемых расходах | Пользователь может вводить данные о предстоящих (планируемых) расходах с целью прогноза бюджета.                                                                      |
| 4 | Ввод данных о кредитах             | Пользователь может вводить данные о текущих или планируемых кредитах (сумма кредита, длительность, процентная ставка и т.п.).                                         |
| 5 | Вывод данных о бюджете             | Пользователь может запросить таблицу о состоянии своего бюджета (текущем и прогнозируемом) на каждый день (в прошлом и будущем) в виде таблицы.                       |
