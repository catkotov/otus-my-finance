# Описание сущностей приложения

### 1. Тип дохода

| № | Поле                                   | Описание поля                                                                                                                                     |
|---|----------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------|
| 1 | Идентификатор типа дохода              | идентификатор типа дохода (целочисленная последовательность)                                                                                      |
| 2 | Наименование дохода                    | текстовое наименование дохода                                                                                                                     |
| 2 | Сумма дохода                           | сумма дохода - если доход периодический, в противном случае - null                                                                                |
| 3 | Признак периодичности дохода           | true - если доход периодический, в противном случае - false                                                                                       |
| 4 | Число месяца дохода                    | число месяца дохода (день дохода) - если доход периодический, в противном случае - null                                                           |
| 5 | Дата начала периода действия дохода    | дата начала периода действия дохода - если доход периодический, в противном случае - null                                                         |
| 6 | Дата окончания периода действия дохода | дата начала периода действия дохода - если доход периодический, null - если период действия еще не закончился или доход не является периодическим |

### 2. Доход

1. Сущность должна хранить начальные накопления (на момент начала заполнения данной сущности).
2. Кортежи данной сущности могут заполняться автоматически на основе данных из сущности "Тип дохода" - для периодических доходов.
3. Автоматическое заполнение должно происходить при просмотре данных из сущности "Бюджет" (например при составлении прогноза будущего бюджета).
4. Признак фиксации защищает запись от автозаполнения.

| № | Поле                 | Описание поля                                                                             |
|---|----------------------|-------------------------------------------------------------------------------------------|
| 1 | Идентификатор дохода | идентификатор дохода (целочисленная последовательность)                                   |
| 2 | Сумма дохода         | сумма дохода                                                                              |
| 3 | Дата дохода          | дата дохода                                                                               |
| 4 | Тип дохода           | ссылка на тип дохода                                                                      |
| 5 | Признак фиксации     | признак фиксации - защита записи от автозаполнения (например после редактирования записи) |
